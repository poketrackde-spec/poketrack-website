Über dieses Set

Das Set Ruf der Legenden umfasst 106 Karten. Am häufigsten vertreten sind Rare Holo (33), Common (31), Uncommon (25), Rare (17). Von 87 Karten existiert zusätzlich eine Reverse-Holo-Variante, die separat bepreist wird. Für 88 der 106 Karten liegt ein aktueller Cardmarket-Preis vor; die Summe ergibt 2.614,73 €.
