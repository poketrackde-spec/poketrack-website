Über dieses Set

Das Set EX Deoxys umfasst 108 Karten. Am häufigsten vertreten sind Uncommon (34), Common (32), Rare Holo (15), Rare (14). Von 95 Karten existiert zusätzlich eine Reverse-Holo-Variante, die separat bepreist wird. Für 89 der 108 Karten liegt ein aktueller Cardmarket-Preis vor; die Summe ergibt 31.369,13 €.
