Über dieses Set

Das Set Sonne & Mond umfasst 163 Karten. Am häufigsten vertreten sind Uncommon (49), Common (44), Rare (17), Rare Holo (16). Von 126 Karten existiert zusätzlich eine Reverse-Holo-Variante, die separat bepreist wird. Für 163 der 163 Karten liegt ein aktueller Cardmarket-Preis vor; die Summe ergibt 556,54 €.
