Über dieses Set

Das Set Paradoxrift umfasst 266 Karten. Am häufigsten vertreten sind Common (81), Uncommon (54), Illustration Rare (34), Ultra Rare (28). Von 162 Karten existiert zusätzlich eine Reverse-Holo-Variante, die separat bepreist wird. Für 266 der 266 Karten liegt ein aktueller Cardmarket-Preis vor; die Summe ergibt 665,15 €.

Alle Preise sind die günstigsten deutschen Angebote in Zustand Near Mint und werden täglich aktualisiert. Ein Klick auf eine Karte zeigt ihren Preisverlauf.
