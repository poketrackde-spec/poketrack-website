Über dieses Set

Das Set Erwachte Legenden umfasst 146 Karten. Am häufigsten vertreten sind Common (48), Uncommon (46), Rare (28), Rare Holo (17). Von 139 Karten existiert zusätzlich eine Reverse-Holo-Variante, die separat bepreist wird. Für 143 der 146 Karten liegt ein aktueller Cardmarket-Preis vor; die Summe ergibt 992,83 €.

Alle Preise sind die günstigsten deutschen Angebote in Zustand Near Mint und werden täglich aktualisiert. Ein Klick auf eine Karte zeigt ihren Preisverlauf.
