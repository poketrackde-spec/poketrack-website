Über dieses Set

Das Set Aufziehen der Sturmröte umfasst 124 Karten. Am häufigsten vertreten sind Common (34), Uncommon (26), Rare (20), Rare Holo (12). Von 92 Karten existiert zusätzlich eine Reverse-Holo-Variante, die separat bepreist wird. Für 124 der 124 Karten liegt ein aktueller Cardmarket-Preis vor; die Summe ergibt 339,33 €.

Alle Preise sind die günstigsten deutschen Angebote in Zustand Near Mint und werden täglich aktualisiert. Ein Klick auf eine Karte zeigt ihren Preisverlauf.
