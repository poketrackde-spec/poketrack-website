Über dieses Set

Das Set Stürmische Funken umfasst 252 Karten. Am häufigsten vertreten sind Common (88), Uncommon (61), Illustration Rare (23), Ultra Rare (21). Von 165 Karten existiert zusätzlich eine Reverse-Holo-Variante, die separat bepreist wird. Für 252 der 252 Karten liegt ein aktueller Cardmarket-Preis vor; die Summe ergibt 825,97 €.

Alle Preise sind die günstigsten deutschen Angebote in Zustand Near Mint und werden täglich aktualisiert. Ein Klick auf eine Karte zeigt ihren Preisverlauf.
