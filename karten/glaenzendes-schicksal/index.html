Über dieses Set

Das Set Glänzendes Schicksal umfasst 73 Karten. Am häufigsten vertreten sind Common (18), Uncommon (13), Ultra Rare (9), Rare (8). Von 46 Karten existiert zusätzlich eine Reverse-Holo-Variante, die separat bepreist wird. Für 73 der 73 Karten liegt ein aktueller Cardmarket-Preis vor; die Summe ergibt 60,23 €.

Alle Preise sind die günstigsten deutschen Angebote in Zustand Near Mint und werden täglich aktualisiert. Ein Klick auf eine Karte zeigt ihren Preisverlauf.
