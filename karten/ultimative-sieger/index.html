Über dieses Set

Das Set Ultimative Sieger umfasst 153 Karten. Am häufigsten vertreten sind Uncommon (47), Common (45), Rare (34), Rare Holo (17). Von 139 Karten existiert zusätzlich eine Reverse-Holo-Variante, die separat bepreist wird. Für 150 der 153 Karten liegt ein aktueller Cardmarket-Preis vor; die Summe ergibt 2.008,12 €.
